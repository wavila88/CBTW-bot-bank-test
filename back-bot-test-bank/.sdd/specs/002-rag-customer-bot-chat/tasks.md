## Phase 6 — Reply in the customer's language, English first (covers HP-2, HP-2b, SP-5)
Result: the bot answers in the language of the question with a single model call. `PromptBuilder` ends the user message with an explicit language reminder, next to the question: identify the language of the question, write the whole reply in it even though the context is in Spanish, and reply in English when the language cannot be told. The rules alone did not hold against a prompt in English around guides in Spanish. A first design asked the model for the language in a separate call; the developer asked to drop it because it doubled the model calls and tokens of every question. The reminder also gives the English fallback of SP-5, so the former Phase 14 is gone.
Test: `Tests/Application/AskQuestionUseCaseTests.cs` asserts that a question costs exactly one model call and that the user message ends with the language reminder.
Manual check: ask in English, in Spanish and with very short phrases; an English question gets an English reply and a Spanish question a Spanish reply, and only app menu names stay in Spanish.

## Phase 7 — Keep the conversation and understand follow-ups (covers HP-3b, HP-3)
Result: the server keeps each conversation in memory by `conversationId`, behind the `IConversationStore` port (Semantic Kernel's `ChatHistory` inside `Infra.AI.SemanticKernel`). `POST /Chat` takes an optional `conversationId` and always returns one, a new one when none is sent. When the conversation has earlier turns, the use case asks the model to rewrite the follow-up so it stands alone (one extra small call, only for follow-ups, never for the first question), searches with the rewritten text, sends the earlier turns as user and assistant messages, and saves the new turn. The history is not limited yet (Phase 8) and an unknown id just starts empty, without a flag (Phase 12).
Test: `Tests/Application/AskQuestionUseCaseTests.cs` asserts that a request without `conversationId` returns a new id, that a given id is kept, that the turn is saved, that a follow-up is rewritten and searched with the rewritten text, and that earlier turns go as user/assistant messages before the question. `Tests/Application/QueryRewriterTests.cs` asserts the rewrite prompt and the cleaning of the model's reply. `Tests/Infra/SemanticKernelConversationStoreTests.cs` asserts that the store saves and returns turns in order, keeps conversations apart by id, and returns nothing for an unknown id. `Tests/Api/ChatControllerTests.cs` asserts that the id goes to the use case and comes back in the response.
Manual check: ask about card payments abroad, then send "and in dollars?" with the returned `conversationId`; the answer follows the earlier topic.
